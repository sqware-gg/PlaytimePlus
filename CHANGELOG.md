# Changelog

## 0.1.0

- Initial PlaytimePlus implementation.
- Added active, AFK, and total playtime tracking.
- Added automatic and manual AFK support.
- Added AFK warning, broadcast, sleep-ignore, and optional kick behavior.
- Added `/playtime`, `/afk`, and `/playtimeplus` commands.
- Added active, total, and AFK leaderboards.
- Added configurable interval and milestone rewards.
- Added reward command/message placeholders, permission gates, and AFK exclusion.
- Added persisted reward claim counters in `players.yml`.
- Added reward progress PlaceholderAPI placeholders.
- Added persistent `players.yml` storage.
- Added optional PlaceholderAPI placeholders.
- Added config-safe `config-new.yml` update references.
